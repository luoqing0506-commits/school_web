# 无错语言 VSCode 扩展

无错语言（WucuoLang）的 VSCode 支持：**语法高亮 + 代码片段补全**。

## 安装（开发模式）

1. 打开 VSCode
2. `文件` → `打开文件夹` → 选这个 `vscode-ext` 目录
3. 按 `F5` 启动扩展开发主机（Extension Development Host）
4. 新建 `.wc` 文件，开始体验彩色中文编程！

## 打包成 .vsix（发布用）

需要装 `vsce` 工具：
```bash
npm install -g @vscode/vsce
vsce package
```
生成 `wucuo-lang-0.4.0.vsix`，别人双击就能装。

## 功能

- ✅ **语法高亮**：关键字（蓝）/ 内置函数（青）/ 数字（橙）/ 字符串（黄）/ 注释（灰）/ 元编程@（紫）
- ✅ **代码片段补全**：打 `量` 出变量模板、打 `功能` 出函数模板、打 `捕获` 出完整错误处理模板
- ✅ 括号自动配对、注释支持、模板字符串识别

## 补全列表（打前缀即出）
