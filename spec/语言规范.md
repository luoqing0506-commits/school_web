# 无错语言（WucuoLang）语言规范 v1.0

> 设计目标：一门"AI 写不错"的中文编程语言
> 核心理念（蒸馏自 Fun / Fluxon / AIL）：
>   1. 危险的事语法上做不到（不是靠规则，是语法无法表达）
>   2. 一个任务只有一种写法（AI 没有选择就没有选择错误）
>   3. 极小可读（一张参考卡让 AI 学会）
>   4. 数字不骗人（精确十进制）

## 1. 文件与编码
- 源码文件扩展名：`.wc`
- UTF-8 编码，中文关键字
- 行注释：`//`；块注释：`/* ... */`

## 2. 关键字（全中文，唯一写法）
| 关键字 | 含义 | 对应其他语言 |
|--------|------|-------------|
| `量` | 声明不可变变量（默认） | const/let |
| `可变` | 声明可变变量 | var/mutable |
| `功能` | 定义函数 | fun/def |
| `纯功能` | 定义纯函数（禁止副作用） | pure fn |
| `若` | if | if |
| `否则若` | else if | elif |
| `否则` | else | else |
| `循环` | 唯一循环 | for/while |
| `对` | 遍历（表的元素/键） | for each |
| `返回` | 返回值 | return |
| `抛错` | 抛出错误 | throw |
| `捕获` | 捕获错误（返回结果表） | try |
| `导入` | 导入模块 | import |
| `真` `假` `空` | true false nil | - |
| `和` `或` `非` | && \|\| ! | - |
| `打印` | 输出 | print |
| `断言` | 断言（失败抛错） | assert |

## 3. 类型系统（强类型 + 自动推断）
| 类型 | 说明 | 例子 |
|------|------|------|
| `数字` | 三层数字塔，精确十进制 | `1` `3.14` |
| `文本` | 字符串 | `"你好"` |
| `布尔` | 真假 | `真` `假` |
| `空` | 空值 | `空` |
| `表` | 唯一数据结构（数组/对象/字典） | `{1,2,3}` `{名:"张"}` |
| `功能` | 函数类型 | `功能(x) -> x*2` |

规则：
- **不可变默认**：`量 a = 5` 后不能 `a = 6`（编译报错）；要改必须 `可变 a = 5`
- **无隐式转换**：`1 + "1"` 编译报错；必须 `转数字("1")` 或 `转文本(1)`
- **强类型**：`量 a: 数字 = 5` 可显式标注，类型不匹配编译期报
- **类型推断**：`量 a = 5` 自动推断为数字

## 4. 函数
```
功能 名字(参数: 类型, 参数2) -> 返回类型 {
    量 x = 参数 + 参数2
    返回 x
}
```
- 纯功能：`纯功能 f(x) { ... }` —— 内部禁止：打印、抛错、改外部变量、调非纯函数（解析期报错）
- 函数是一等公民：可赋值、当参数、放表里
- 参数可显式标类型：`参数: 数字`

## 5. 控制流
```
若 条件 {
} 否则若 条件 {
} 否则 {
}

循环 条件 {        // 条件式循环（唯一形式，去掉了三段式防AI写错）
}

对 元素 in 表 {    // 遍历
}
```

## 6. 表（唯一数据结构）
```
量 用户 = { 名: "张三", 年龄: 18 }     // 对象式
量 数组 = { 1, 2, 3 }                   // 数组式
用户.名          // 属性访问
用户["名"]       // 下标访问
数组[0]          // 数组下标（从0开始）
```

## 7. 错误处理（错误即值）
```
抛错("出错了")           // 抛出任意值
量 结果 = 捕获(可能失败)  // 返回 {成功: 真/假, 值: ..., 错误: ...}
若 结果.成功 { 打印(结果.值) } 否则 { 打印(结果.错误) }
```

## 8. 内置函数
| 函数 | 说明 |
|------|------|
| `打印(...)` | 输出 |
| `长度(x)` | 文本长度/表元素数 |
| `类型(x)` | 返回类型名 |
| `转数字(x)` `转文本(x)` `转布尔(x)` | 显式转换 |
| `键(t)` | 表的键列表 |
| `含(t, k)` `删(t, k)` | 键检查/删除 |
| `克隆(t)` | 表浅拷贝 |
| `合并(t, src...)` | 表合并 |
| `断言(条件, 消息)` | 断言 |
| `读入()` | 从标准输入读一行 |
| `数字塔` | 0.1+0.2==0.3，永不溢出 |

## 9. 防错设计（核心卖点）
1. **不可变默认** —— 变量默认只读，防止意外改状态
2. **无隐式转换** —— 所有转换显式，杜绝类型混用
3. **纯函数强制** —— 纯功能里副作用语法报错（不是警告）
4. **单一循环** —— 只有 `循环`，去掉 for 三段式（AI 常把 i++ 写错）
5. **精确数字** —— 0.1+0.2==0.3，杜绝浮点误差
6. **错误即值** —— 必须检查结果表，禁止静默吞错
7. **最小关键字集** —— 15个关键字，AI 记不错

```
├── parser.py         # 递归下降 → AST
├── checker.py        # 类型检查 + 防错规则
├── interpreter.py    # 树遍历解释器
├── number.py         # 三层数字塔
├── builtins.py       # 内置函数
├── spec/
│   └── reference-card.md   # AI 参考卡
├── examples/         # 示例
└── tests/            # 测试
```
