# 无错语言 参考卡（AI 专用）

> 这是一张完整的语言参考卡。贴给任何 AI（Claude/GPT/Gemini/本地模型），
> 它就能写出语法正确的无错语言（WucuoLang）程序。
> 文件扩展名：`.wc`，UTF-8 编码，全中文关键字。

## 一、立即能写的例子

```
打印("你好，世界！")
```

## 二、语法速查（全部规则）

### 变量（默认不可变！）
```
量 名字 = "张三"        // 不可变，之后不能改
可变 分数 = 80          // 可变，之后可以改
分数 = 90               // OK（可变）
// 量 分数 = 80 之后 分数 = 90 会编译报错：不可变
```

### 函数
```
功能 双倍(x) -> 数字 {    // 名字(参数) -> 返回类型
    返回 x * 2
}
纯功能 纯算(x) -> 数字 {  // 纯函数：禁止打印/抛错/改外部变量
    返回 x + 1
}
操作 查库存(商品) -> 数字 {  // 操作函数：有副作用（调API/读写文件），可能失败
    返回 42
}
量 匿名 = 功能(x) -> 数字 { 返回 x * 3 }   // 匿名函数

// 操作函数必须捕获兜底（编译器强制）：
量 r = 捕获(查库存("手机"))
若 r.成功 { 打印(r.值) } 否则 { 打印("降级:", r.错误) }

// 默认参数：调用时可不传，用默认值
功能 打招呼(名字, 语气 = "你好") {
    打印(语气, 名字)
}
打招呼("小明")              // 你好 小明

// 多返回值：函数返回表 + 解构赋值
功能 算圆(半径) -> 表 {
    返回 { 3.14 * 半径 * 半径, 2 * 3.14 * 半径 }
}
量 面积, 周长 = 算圆(10)    // 面积=314, 周长=62.8
```

### 分支
```
若 条件 {
} 否则若 条件2 {
} 否则 {
}
```

### 循环（只有这一种）
```
循环 条件 {              // 条件式循环（相当于 while）
}
对 元素 在 表 {          // 遍历表/文本（给值）
}
对 键, 值 在 表 {        // 键值对遍历
}
```

### 表（唯一数据结构：既是对象也是数组）
```
量 对象 = { 名: "张三", 年龄: 18 }
对象.名                 // "张三"
对象["年龄"]            // 18
对象.城市 = "北京"       // 新增字段

量 数组 = { 10, 20, 30 }
数组[0]                 // 10
```

### 错误处理（错误即值）
```
抛错("出错了")           // 抛出
量 结果 = 捕获(可能出错)   // 返回 {成功: 真/假, 值: ..., 错误: ...}
若 结果.成功 {           // 必须检查 .成功 并处理两种分支（编译器强制）
    打印(结果.值)
} 否则 {
    打印(结果.错误)
}
// ⚠️ 捕获() 结果不能丢弃（编译报错）
```

### 模板字符串
```
量 名 = "小明"
打印(`我是${名}，${年龄 + 1}岁`)
```

## 三、类型（自动推断，不用写）

| 类型 | 例子 |
|------|------|
| 数字 | `1` `3.14`（精确十进制，0.1+0.2==0.3） |
| 文本 | `"你好"` |
| 布尔 | `真` `假` |
| 空 | `空` |
| 表 | `{1,2,3}` `{名:"张"}` |
| 功能 | `功能(x) { 返回 x }` |

| `读入()` | 读一行输入 |

## 五、AI 写代码的 7 条铁律（防错）

1. **变量默认只读**——要修改必须先 `可变` 声明
2. **禁止隐式转换**——`1 + "1"` 会编译报错，必须 `转数字("1")` 或 `转文本(1)`
3. **纯函数里不能**：打印、抛错、改外部变量、调非纯函数（编译报错）
4. **循环只有 `循环 条件 {}`**——没有 for 三段式，别写 `i++` 那种
5. **表访问不存在的键会运行时报错**——访问前用 `含(t, k)` 检查
6. **函数调用参数数量必须匹配**——多了少了都编译报错
7. **错误必须处理**——可能失败的操作用 `捕获()` 包住，检查 `.成功`
